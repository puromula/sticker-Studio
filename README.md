# Sticker Studio

Creá **stickers con sonido para WhatsApp** a partir de un GIF, una imagen o un video. Agregá el audio que querás y enviá el sticker a tu propio chat. Disponible para **Android y Windows**.

## Descargas

| Plataforma | Archivo | Cómo abrirlo |
| --- | --- | --- |
| Android | [Sticker Studio 0.3.3 · APK](https://github.com/puromula/sticker-Studio/releases/download/v0.3.3/StickerStudio-Android-0.3.3.apk) | Descargá e instalá el APK en un dispositivo ARM64. |
| Windows | [Sticker Studio · ZIP](https://github.com/puromula/sticker-Studio/releases/download/v0.3.3/StickerStudio.zip) | Extraé el ZIP y abrí `Abrir.cmd` con Node.js 20 o posterior instalado. |

## Creá tu primer sticker

1. Vinculá WhatsApp desde Sticker Studio.
2. Elegí un GIF, una imagen compatible o un video.
3. Agregá un sonido o usá el audio del video. Escribí un nombre.
4. Tocá **Enviar a mi WhatsApp** y abrí tu chat contigo mismo.

El audio del sticker dura hasta cinco segundos. En Android también podés guardar tus creaciones en una galería local, aplicar el efecto **Bocina del 2007** y alternar entre tema claro y oscuro.

## Vinculación con WhatsApp

El envío usa una integración no oficial de WhatsApp y requiere vincular un dispositivo. Su funcionamiento puede cambiar si WhatsApp modifica el protocolo.
